# Глоссарий

> **Статус:** актуально · **Обновлять при:** появлении нового термина в документах или коммуникации, изменении смысла существующего

Термины упорядочены по темам. Подробности поведения — в [spec/colony-language.md](spec/colony-language.md), архитектурный контекст — в [architecture.md](architecture.md).

## Сюжет и сценарий

| Термин | Определение |
|---|---|
| **Клякса** | Планета, на которую Вейланд-Ютани переводит оборудование и выживших с LV-426 для добычи креатина. Место действия целевого ТЗ — [requirements.md](requirements.md). Отсылка — Олег Дивов, «Саботажник». |
| **LV-426** | Исходный сценарий-предшественник (300 домов, «Чужие»). Историческое имя: пакет фронтенда называется `lv-426-monitor`, файлы экспорта UI — `lv426-report-*.csv`. В сюжетной линии добыча на LV-426 закрыта. |
| **Креатин** | Ресурс, добываемый на Кляксе для омоложения. Добыча в шахте, перевозка шахта→склад→медцентр, продажа (`creatine_sale`) и лечение жителей за счёт медицинского запаса. Логика — `CreatineManager`, см. [architecture.md](architecture.md). |
| **Сценарий «5000 домов»** | Целевая нагрузка: посёлок на 5000 домов (~20 028 контекстов поведения, снимок ~25 936 объектов). Файлы: `examples/physics/full-5000.json` (conformance-сценарий: настройки мира из `full.json`) и `examples/physics/settlement-5000.json` (полная экосистема Лес/Море). |
| **Conformance-вектор** | Файл в [conformance/](../conformance): программа, начальное состояние, кадры и ожидаемые намерения/события/состояние. Кросс-проверяет три исполнения ВМ (см. [architecture.md](architecture.md), диаграмма 2.3). |

## Исполнение

| Термин | Определение |
|---|---|
| **Тик** | Единица модельного времени: снимок мира → исполнение поведения → сбор намерений → проверка/разрешение конфликтов → физика → фиксация. Шаг по умолчанию 1 с. Подробно — [spec/runtime-tick.md](spec/runtime-tick.md). |
| **Контекст поведения** | Независимый экземпляр программы: отдельные переменные, таймеры и случайный поток при общем переиспользуемом байт-коде. При 5000 домах — 20 028 контекстов. |
| **Colony** | Предметный DSL поведения: `event`, `behavior ... for ...`, `on`, `every`, `send`. Грамматика — `colony-dsl-parser/src/main/antlr/Colony.g4`, спецификация — [spec/colony-language.md](spec/colony-language.md). |
| **.cvm** | Двоичный артефакт CVM v2 (стековый байт-код + таблицы + SHA-256). Спецификация — [spec/cvm-format.md](spec/cvm-format.md). |
| **ReferenceVm** | Эталонная JVM-реализация стековой ВМ (`colony/runtime/ReferenceVm.kt`). Режимы `run`/`serve` — «reference». |
| **hh-vm** | Нативная C++20 реализация ВМ (`native/`). Текущий режим — процесс на сущность (`run-native`/`serve-native`); целевая схема общего исполнителя не реализована. |
| **Broker / fleet** | Координатор, запускающий процессы ВМ и доставляющий им кадры наблюдений (`ProcessFleet`, `NativeBroker`). |
| **Fast-режим** | `run-fast`/`benchmark-fast`: расчёт без промежуточных полных снимков; JSONL становится журналом фактов (промежуточные кадры `full=false`). |
| **Семейство benchmark** | `benchmark` / `benchmark-live` / `benchmark-fast` — замеры фаз шага, кодирования и скорости; выводят SHA-256 последнего полного снимка для сверки. |

## Ядро мира

| Термин | Определение |
|---|---|
| **WorldKernel** | Физическое ядро: интеграция моря, угроз, ПВО, креатина, респираторов и ремонта. Личное состояние — у контекстов, физический мир — только здесь. |
| **SpatialIndex** | 2D пространственный хеш-индекс (сетка ячеек): запрос соседей `queryRadius` за O(1) вместо O(N²). ADR 0003. |
| **SeaController** | Контроллер моря: эрозия прибрежных строений, цикл смещающегося облака морского тумана (~100×100 домов). Внутри тумана — урон без респираторов, коррозия ПВО. |
| **DefenseAndThreats** | Подсистема угроз и защиты: `FlyingCrocodile` (шум Перлина, пул `CrocodilePool` на 128 слотов) и `AirDefenseUnit` (ПВО периметра и крыш). |
| **CreatineManager** | Экономика креатина: добыча с коэффициентом синергии `S = 1.0 + 9.0 × min(1, W/5000)`, склад, продажа, исцеление в медцентре. |
| **TaskQueue** | Глобальная очередь ремонтных задач, привязанных к координатам через spatial-индекс. |
| **Topology** | Генерация топологии посёлка: дома, ЛЭП, водопровод, лес/море, склад, медцентр, ПВО. |
| **Ровер** | Наземное транспортное средство. В settlement-5000 флот 150 шт. со строгими ролями: 50 ремонтных (`crew-*`), 50 грузовых (`cargo-*`), 50 такси (`transport-*`). Поведение — [spec/runtime-tick.md](spec/runtime-tick.md). |
| **UPS** | Источник бесперебойного питания дома: заряжается как потребитель класса 0, при дефиците разряжается; нулевой запас меняет связность сети. |
| **MonthClosed** | Событие закрытия месяца: начисления ежемесячных расходов; разделение периодов пока требует проверки. |

## Наблюдение

| Термин | Определение |
|---|---|
| **ObserverGateway** | HTTP/SSE-шлюз (:8080): публикует зафиксированные снимки, принимает управление прогоном. Спецификация — [spec/http-api.md](spec/http-api.md). |
| **Снимок (кадр)** | Полное состояние мира на тике: `entities`, `effects`, `events`, `postings`. Формат — [spec/http-api.md](spec/http-api.md), типы — `frontend/src/domain/types.ts`. |
| **Компактный формат** | `GET /stream?format=compact` (версия 2): полная база при подключении, затем изменения полей и `removed`. Средний кадр 9,29 МБ → 1,33 МБ. |
| **gap** | Служебное SSE-событие: запрошенная история вытеснена, клиенту отправляется новая полная база. |
| **contract.json** | Генерируемый предметный контракт языка/мира (`docs/generated/contract.json`): единицы, схемы, виды сущностей, intrinsics, события ядра. Не описывает HTTP. Команда CLI `contract`. |
