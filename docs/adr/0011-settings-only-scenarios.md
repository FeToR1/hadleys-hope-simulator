# ADR 0011: сценарии только на Colony settings

> **Статус:** принято · **Аудитория:** разработчики и авторы сценариев · **Обновлять при:** изменении подготовки сценариев · **Источник истины:** Colony.g4, SettingsScenario.kt, Scenario.kt

## Контекст

После ADR 0010 основной сценарий использует `.settings`, но остальные примеры, Docker и тесты
ещё зависят от JSON-каталогов и JSON-сценариев. Пользователь требует полностью перевести эти входы
на Colony и удалить старые файлы.

## Решение

Единственный авторский вход запуска — `.settings`. Удалить JSON-загрузчик и все JSON-файлы
из `examples/`; обновить тесты, Docker, задачи и актуальные инструкции.
Добавить `include "relative.settings";` для общих исходников, констант и шаблонов.
Подключаемая библиотека не задаёт населения, мир или длительность запуска; циклы подключений
запрещены, повторное подключение одного файла не дублирует объявления. Пути исходников относительны
объявившему их файлу. Константы библиотеки вычисляются перед локальными константами.

Стенды без физического мира сохраняются: `at tick for "entity-id" { observation = expression; }`
задаёт изменение наблюдений. Константные записи `Position { x: 1m, y: 2m }` и
`Target { id: "entity-id" }` используют AST выражений и схемы записей Colony.
Для `Target` в стенде достаточно `id`: поля, вычисляемые стендом, можно опустить.
Размерности, ссылки, имена полей, границы тиков и запрет сочетания `world` с изменениями проверяются.

Генерируемый манифест, контракт, conformance-векторы, внешний HTTP/SSE и JSON инструментов
сохраняют свои форматы: они не являются авторскими сценариями.

## Альтернативы

Оставить JSON совместимость — сохраняет два пользовательских формата и не выполняет требование.
Дублировать шаблоны во всех файлах — не требует `include`, но затрудняет синхронное изменение примеров.

## Последствия

CLI отвергает JSON вместо молчаливого выбора старого загрузчика. Программы поведения и физика
остаются прежними; перенос проверяется отпечатками развёрнутых экземпляров, мира, изменений
наблюдений и бинарной программы. Контракт языка и conformance-артефакты перегенерируются.
