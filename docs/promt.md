Первый промт

Задача: Разработать фронтенд-модуль «Интерактивная 2D-карта поселения и Топология сетей» для системы мониторинга симуляции LV-426.
Окружение и Технологический стек:

* Среда исполнения: Node.js v24.14.0 (учитывай синтаксис и особенности данной версии при написании скриптов сборки, если они потребуются).
* Язык: TypeScript с жесткой типизацией.
* Интерфейс и панели (UI): React (используется как декларативная обвязка для табов, боковых панелей управления и вывода текстовых метрик/логов).
* Графическое ядро карты: PixiJS v8 + плагин масштабирования/перетаскивания (например, @pixi/viewport или аналогичный контейнер, совместимый с v8) для отрисовки сетки поселения и агентов на GPU.
* Визуализация графов и инфраструктуры: AntV G6 (используется для построения интерактивных схем электросетей, водоснабжения и логических KPN-связей брокера).

Контекст проекта и ограничения производительности:

   1. Масштаб: Симуляция шахтерского поселка состоит из ~300 домов. Физика и логика распределены: у каждого дома, каждого прибора (обогреватель, чайник), а также жителей (300+ человек) и ксеноморфов есть собственная стековая ВМ, запущенная в отдельном процессе ОС. Суммарно на фронтенд одновременно транслируется состояние около 1300+ активных сущностей.
   2. Транспорт данных: Данные приходят от центрального Координатора (World Kernel) через WebSockets/SSE пакетами (батчами) раз в 100–500 мс.
   3. Оптимизация: Обновление объектов в PixiJS v8 и AntV G6 должно происходить по ссылке (мутацией свойств существующих инстансов), без полного пересоздания объектов сцены на каждом тике. Это необходимо, чтобы избежать утечек памяти и микрофризов интерфейса при обработке частых батчей данных. React должен управлять только внешними панелями (Sidebar) и не должен ререндерить графическую сцену.

Интерфейсы данных (Входной контракт):

interface EntityState {
  id: string;
  pid: number;
  type: 'house' | 'heater' | 'kettle' | 'civilian' | 'xenomorph' | 'power_node';
  status: 'nominal' | 'warning' | 'critical' | 'dead';
  metrics: {
    temperature?: number;
    power_consumption?: number;
    water_level?: number;
    stress?: number;
  };
  connectedTo: string[]; // ID смежных узлов для графа сетей AntV G6
  coordinates: { x: number; y: number };
}
interface TickBatch {
  tickId: number;
  timestamp: number;
  entities: EntityState[];
}
