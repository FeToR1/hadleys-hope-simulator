# LV-426 frontend monitor

## Запуск

```bash
npm install
npm run dev
```

`npm run build` выполняет строгую проверку TypeScript и production-сборку.

Приложение сразу подключается к симуляции: SSE-поток `/stream` передаёт тики через `StateManager.ingest(TickBatch)`. Адрес шлюза для dev-сервера задаёт `VITE_BACKEND_URL` (по умолчанию `http://127.0.0.1:8080`). Имитации нет: пока шлюз не запущен, карта ждёт первый снимок.

Движок Pixi создаётся один раз в `useEffect`, после чего обновляет существующие объекты карты. Обзор сетей отрисовывается средствами React без графического движка и расчёта раскладки графа.

На вкладке топологии электричество и вода разделены. Обзор показывает оборудование, распределительные линии и количество домов с проблемами. Нажатие на линию открывает подключения её домов; поиск работает по ID дома или узла, фильтр «Только проблемы» оставляет затронутые подключения. Большие линии разбиты на страницы по 30 домов. Вода сгруппирована по 20 домов для просмотра; это не дополнительные физические связи. Учитываются только связи, переданные брокером: отсутствующие соединения с источниками не дорисовываются. Цвет и счётчики обновляются по снимкам без очереди перерисовок и пересчёта геометрии.

Наведение на дом на Pixi-карте открывает tooltip с PID и метриками. Клик по сущности на карте или в подключениях сети открывает инспектор. Шаги «Логики каскада событий» переводят к соответствующему участку сети или объекту на карте.

Карта различает типы объектов силуэтом и цветом: голубые дома, светлые жители,
янтарные роверы, бирюзовые морпехи и розовые ксеноморфы. Легенда раскрыта по
умолчанию; кнопка «Легенда» сворачивает её. Предупреждения и гибель отмечаются
дополнительной обводкой и знаком, сохраняя цвет типа. У каждого вида подвижных
объектов есть отдельная кнопка видимости. «Подписи» включает названия при
приближении; пересекающиеся подписи скрываются. Выделение снимается крестиком
или Escape, когда фокус находится на карте.

Существа в одной точке показываются значком с числом; пассажиры внутри видимого
ровера учитываются на его значке. При скрытии роверов пассажиры снова видны.
Жители в пути отображаются по фактическим координатам, а угрозы остаются видны
при отдалении. Символы карты и легенды используют общий набор SVG из
`src/domain/mapPresentation.ts`. Сетка — координатная подложка, не дороги и не
связи. Забор колонии рисуется линией по концам секций, которые сообщает ядро;
сломанные секции выделены красным до ремонта. Электричество и водопровод здесь не изменены: их будущие слои обозначены
отдельными неактивными кнопками, существующий обзор сетей работает как прежде.

Тики и статус прогона приходят через SSE `/stream`; пути можно заменить в [App.tsx](./src/App.tsx). Connected в Live означает открытое соединение с потоком. Пауза, скорость и завершение обновляются сервером даже без нового тика; команды отправляются через POST `/control/...`.

При обрыве EventSource автоматически переподключается и передаёт `Last-Event-ID`. Сервер восстанавливает пропущенные тики по порядку из ограниченной истории (до 256 снимков и 16 Mi символов JSON, с сохранением хотя бы последнего снимка). Если история уже вытеснена, интерфейс предупреждает о неполных событиях, графиках и расходах. Повторы тиков не учитываются дважды. На первом подключении также передаётся доступная история текущего прогона.

Обрыв потока не подменяет данные: интерфейс показывает статус соединения и ждёт переподключения. State Manager использует animation-frame доставку для графики, throttling 200 мс для Sidebar и FIFO из 200 логов. Seed и tick видны в шапке, CSV-отчет доступен в Sidebar.

Каждый принятый тик также добавляется в фазовый буфер аттрактора (строго последние 10 000 точек). Координаты `x/y/z` соответствуют средней температуре домов, суммарной мощности в кВт и отрицательной сумме ledger postings. Sidebar показывает классификацию режима (`stationary`, `periodic`, `chaotic`, `collapse`) и позволяет скачать `Экспорт аттрактора в CSV` с колонками `TickID,AvgTemperature,TotalPower,GlobalBudget`.

Кнопка `Открыть 3D вихрь` в Sidebar лениво создает Three.js WebGL-визуализатор последних 3000 фазовых точек. Вихрь использует OrbitControls, спиральную координату `y = tickId * 0.05`, температурно-зависимый радиус и переиспользуемую `BufferGeometry`; при закрытии renderer и WebGL-контекст освобождаются.
