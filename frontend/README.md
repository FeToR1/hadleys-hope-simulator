# LV-426 frontend monitor

## Запуск

```bash
npm install
npm run dev
```

`npm run build` выполняет строгую проверку TypeScript и production-сборку.

Приложение стартует с автономным генератором: 300 домов, приборы, жители и два узла питания. Генератор предоставляет ручной `step()` для headless-тестов и запускает обновления каждые 300 мс. В режиме «Брокер» SSE-поток передаёт реальные тики через `StateManager.ingest(TickBatch)`, не меняя Pixi/G6 компоненты.

Графические движки создаются один раз в `useEffect`, после чего обновляют существующие display objects и модели узлов/ребер. React управляет вкладками и Sidebar, а не жизненным циклом отдельных объектов сцены.

На вкладке топологии отображаются только дома и узлы питания. Связи строятся направленно от `power_node` к дому, без обратных дублей. Для плотной звезды подписи домов скрыты, а подписи узлов питания остаются видимыми; панель `+ / - / центр` управляет камерой независимо от drag/zoom жестов.

Наведение на дом на Pixi-карте или узел в G6 открывает tooltip с PID и метриками. Клик по сущности включает контекстную подсветку связей. При аварии `power-1` появляется вкладка «Логика каскада событий»: шаги сети, тепла, гидравлики и экономики кликабельны и переводят соответствующую камеру к источнику или дому.

В шапке доступны источники `Имитация` и `Брокер`. В Mock-режиме `/health` проверяется раз в 2 секунды. В Live-режиме тики и статус прогона приходят через SSE `/stream`, без опроса `/health`; пути можно заменить в [App.tsx](./src/App.tsx). Connected в Live означает открытое соединение с потоком. Пауза, скорость и завершение обновляются сервером даже без нового тика; команды отправляются через POST `/control/...`.

При обрыве EventSource автоматически переподключается и передаёт `Last-Event-ID`. Сервер восстанавливает пропущенные тики по порядку из ограниченной истории (до 256 снимков и 16 Mi символов JSON, с сохранением хотя бы последнего снимка). Если история уже вытеснена, интерфейс предупреждает о неполных событиях, графиках и расходах. Повторы тиков не учитываются дважды. На первом подключении также передаётся доступная история текущего прогона.

При недоступном брокере переключение из Mock в Live не выполняется; обрыв уже открытого Live-потока не подменяет реальные данные имитацией. State Manager использует animation-frame доставку для графики, throttling 200 мс для Sidebar и FIFO из 200 логов. Seed и tick видны в шапке, CSV-отчет доступен в Sidebar.
