# Ограничения целевой платформы компилятора

Язык Colony в дальнейшем будет переводиться в байт-код для простых стековых
виртуальных машин.

Для данной части проекта это означает только то, что синтаксис и AST должны
оставаться независимыми от конкретного бинарного формата и реализации VM.

В текущем проекте не реализуются:

- байткод-интерпретатор;
- C/C++ виртуальная машина;
- runtime VM;
- бинарный формат исполняемого файла.

Эта информация сохранена как ограничение для будущих этапов компилятора.
