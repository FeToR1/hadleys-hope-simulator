# Черновики синтаксиса

Эти программы написаны для видов сущностей, которых нет в контракте: реактор, холодильник,
узлы отопления и воды, мусоровоз. Они не компилируются и не входят в проверку примеров —
это заявка на следующую итерацию, а не рабочий код.

Чтобы программа отсюда заработала, нужно добавить её вид в
[контракт](../../src/main/kotlin/colony/semantics/Contracts.kt): поля наблюдений, возможности и,
если нужно, новую предметную команду. После этого ядро мира должно научиться считать
соответствующую физику, а сценарий — создавать такие объекты.

Рабочие примеры лежат на уровень выше: `heater.colony`, `resident.colony`, `xenomorph.colony`,
`minimal.colony`, а полный посёлок с физикой — в [examples/physics](../../../examples/physics).
